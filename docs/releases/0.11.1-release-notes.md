# AssegaiPHP Core 0.11.1

Core 0.11.1 corrects custom source-directory rendering and the dependency baseline
for the coordinated 0.11 framework line.

## Changes

- PHP views and Twig/component templates honor the application's configured
  `sourceRoot`, including adjacent styles. The selected source directory remains
  bound to that application across requests.
- Invalid, missing custom or escaping source directories fail explicitly.
  An omitted `sourceRoot` retains the native `src` default and existing standalone
  root selection.
- Core selects Common, Forms, Util and Validation on `~0.11.0`, with the existing
  compatible Attributes `~1.0.3` dependency. Forms selects matching Collections,
  Util and Validation dependencies.
- The release policy records the complete module inventory and the historical
  version matrix. Framework packages use 0.11, the pre-existing queue adapters
  advance to 1.2 with Common 0.11, and Attributes retains its compatible line.
  A baseline request includes the full module, compatibility and Website release
  effort before a version decision.

## Upgrade

Use the corrected Console `~0.11.1` and Core `~0.11.1` baselines after the
coordinated packages are published. Update installed framework modules together;
retain the mapped legacy streams. Review custom constraints before resolving
with all dependencies and run the application's tests.

A custom `sourceRoot` must be an existing relative directory contained within
the application. Restart the application after changing source metadata.
`ApplicationPaths` retains its seven constructor fields and PHP 8.4 remains the
minimum supported version.

This maintenance release preserves the 0.11.0 bootstrap contracts.
